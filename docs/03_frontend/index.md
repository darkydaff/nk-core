# Frontend

User interface and client-side logic.

## 🎨 Design System
- Modern, responsive UI using custom CSS and Twig.
- Dynamic updates via AJAX/JSON.
- Template Engine: **Twig 3.x**.
- Entry Point: `templates/layout.twig`.
